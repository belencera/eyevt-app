# EYEVT

Eye Visual Therapy. Web para practicar ejercicios de visión.

## Instalación

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000).

## Estructura

- `/games/eye-tracking` — seguimientos
- `/games/sacades` — sacádicos

## Stack

Next.js, React, Tailwind CSS.
